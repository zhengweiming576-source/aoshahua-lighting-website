# AOSHAHUA Lighting — Independent Website V1.0

This package is designed for GitHub + Vercel and does not depend on Accio.

## Files
- index.html — Home
- products.html — Product collections
- custom.html — OEM/ODM & project customization
- about.html — Company profile
- contact.html — Inquiry page
- assets/styles.css — Global design
- assets/app.js — Mobile menu / filters / demo form
- assets/images/ — Local placeholder visuals
- vercel.json — Vercel settings
- robots.txt / sitemap.xml — SEO starter files

## Before going live
1. Replace placeholder SVG images with your real product/factory/project images.
2. Update the public WhatsApp number.
3. Confirm the public email address.
4. Replace YOUR-DOMAIN.com in robots.txt and sitemap.xml.
5. Connect the inquiry form to Formspree / HubSpot / your own API.
6. Add Google Analytics / Meta Pixel only after your privacy policy is ready.

## Upload to GitHub
Open your repository > “uploading an existing file”.
Upload ALL files and folders from this package (not only the ZIP).
Commit changes.

## Deploy to Vercel
Import the GitHub repository into Vercel.
Framework preset: Other
Build command: leave empty
Output directory: leave empty
Deploy.

## Future AI editing
Because this is plain HTML/CSS/JS, AI can continue editing every page.
Your custom domain remains unchanged when the site content is updated.
